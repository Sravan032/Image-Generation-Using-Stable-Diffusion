# Stable Diffusion Image Generation

## Project Overview

This project demonstrates an interactive **text-to-image generation application** built using **Stable Diffusion, Hugging Face Diffusers, Python, PyTorch, and Gradio**.

The application runs on **Google Colab with GPU acceleration** and allows users to generate AI-generated images from natural language prompts through an interactive web interface.

The project also evaluates Stable Diffusion inference performance by measuring image generation time and experimenting with different inference-step configurations.

## Features

- Generate images from natural language text prompts
- Stable Diffusion v1.5 image generation
- GPU-accelerated inference using CUDA
- Interactive Gradio web interface
- Configurable inference steps
- Configurable guidance scale
- Displays image generation time
- Performance evaluation across multiple prompts
- Comparison of inference configurations for generation-time optimization
- Google Colab-based execution

## Technology Stack

- **Programming Language:** Python
- **Generative AI:** Stable Diffusion v1.5
- **ML Framework:** PyTorch
- **Model Library:** Hugging Face Diffusers
- **Interface:** Gradio
- **Execution Environment:** Google Colab
- **Hardware Acceleration:** CUDA GPU

## Performance Evaluation

A baseline experiment was conducted using:

- **Inference Steps:** 30
- **Guidance Scale:** 7.5
- **Images Generated:** 20

### Baseline Results

| Metric | Result |
|---------|---------|
| Images Generated | 20 |
| Total Generation Time | 110.23 seconds |
| Average Generation Time | 5.51 seconds/image |
| Fastest Generation | 5.20 seconds |
| Slowest Generation | 6.93 seconds |

A second experiment was performed by reducing the inference steps from **30 to 20** while keeping the guidance scale fixed at **7.5**.

This optimization reduced the image generation time by approximately **29%**, demonstrating the effect of inference-step configuration on Stable Diffusion generation latency.

## Setup Instructions

### 1. Open Google Colab

[Run in Google Colab](https://colab.research.google.com/drive/1jW6JpdIwCN5Jf7dTLK3w14mjLXhnlJ9D?usp=sharing)

### 2. Enable GPU

In Google Colab:

```text
Runtime → Change runtime type → T4 GPU
```

GPU acceleration is required because the project uses half-precision (`float16`) inference.

### 3. Install Dependencies

```bash
pip install -q diffusers transformers accelerate safetensors gradio
```

### 4. Run the Application

Create or run the following files:

```text
image_generation.py
app.py
```

Then execute:

```bash
python app.py
```

The Gradio application will generate a temporary public URL.
